# Vitrine Glauber Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task in the authorized workspace.

**Goal:** Reconstruir a experiência pública e tornar o código compreensível para quem começa em Vue.

**Architecture:** Páginas declarativas, componentes com uma responsabilidade, dados separados da apresentação e filtros controlados pela URL. Pinia compartilha apenas catálogo e favoritos. Identidade do Figma documentada e fontes locais.

**Tech Stack:** Vue 3, Quasar 2, Vite 7, JavaScript, Pinia, Vue Router, Node test runner e Playwright.

**Spec:** `docs/superpowers/specs/2026-10-29-vitrine-design.md`

## Global Constraints

- Azul #1746C8, rosa #EC4899, amarelo #FFD43B, azul escuro #142D59, branco #FFFFFF e cinza #F5F7FA.
