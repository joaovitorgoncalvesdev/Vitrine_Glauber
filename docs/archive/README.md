# Referências anteriores

Este diretório preserva os protótipos e ativos da versão anterior. Não participa do aplicativo nem é copiado para a pasta pública de produção.

- `design-demos/`: alternativas de interface anteriores à reconstrução.
- `public/brand/`: assinaturas e ícones substituídos pelos ativos oficiais do Figma.
- `public/fonts/`: fontes anteriores à adoção de Outfit e Inter.
- `public/images/`: PNGs originais; o aplicativo utiliza derivados WebP mais leves.

Para alterar o site atual, comece pelo guia `docs/GUIA-VUE.md` e pelos arquivos de `src/`.
